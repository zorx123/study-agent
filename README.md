# Study Agent — консольный ИИ-агент-помощник для учёбы

Агент на Python, который сам решает, когда ему нужен инструмент, вызывает его и отвечает по результату.

## Что умеет
- **calculate** — считает выражения (безопасно, без `eval`)
- **save_note / list_notes** — сохраняет и показывает заметки (файл `notes.json`)
- **get_time** — говорит текущую дату и время

Пример диалога:

```
Ты: Сколько будет 12*(3+4)? И запиши заметку: сдать отчёт в пятницу
  [инструмент] calculate({'expression': '12*(3+4)'}) -> 84
  [инструмент] save_note({'text': 'сдать отчёт в пятницу'}) -> Заметка сохранена (всего: 1)
Агент: 12*(3+4) = 84. Заметку сохранил.
```

## Как это работает
1. Запрос пользователя и описание инструментов уходят в модель.
2. Если модель вернула `tool_use`, программа запускает нужную функцию.
3. Результат отправляется обратно модели как `tool_result`.
4. Цикл повторяется, пока модель не даст текстовый ответ. Лимит — 6 шагов (`MAX_STEPS`), чтобы агент не зациклился.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY="твой_ключ"   # Windows: set ANTHROPIC_API_KEY=твой_ключ
python agent.py
```
Модель можно сменить переменной `MODEL`.

## Тесты
Тесты не требуют API-ключа: цикл агента проверяется на поддельном клиенте.
```bash
pip install pytest
pytest
```

## Структура
```
agent.py          цикл агента и консольный интерфейс
tools.py          инструменты и их описание для модели
tests/            тесты инструментов и цикла агента
```
